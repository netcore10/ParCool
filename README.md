# ParCool MOD

> **26.2 port (unofficial, made with AI):** the `26.2` branch ports ParCool to Minecraft **26.2** / NeoForge **26.2.0.93**, with a more forgiving vault (1-block landing, 60°, sprint grace kept during vaults). The port was written by Claude (Anthropic's AI model, via Claude Code) under my direction and tested in game. It is not made or endorsed by alRex_U; don't report issues from it upstream. Build: `./gradlew build` → `build/libs/ParCool-26.2-3.4.3.3-NF.jar`.


**Welcome to this project!**

*ParCool* is a mod of Minecraft, for more *Cool* Actions like *Parkour*.  
It's inspired by [SmartMoving](https://www.curseforge.com/minecraft/mc-mods/smart-moving). That was a very great mod.

Players can do more actions such as...

+ Grabbing Cliffs
+ Running Faster
+ Roll
+ Backflip
+ WallJump
+ CatLeap  
  etc

If it made you traceurs or traceuses ; parkour practitioners, I couldn't be happier!!

This project is always ready to accept your contribution.
